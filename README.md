```
Usage: ./fetch_subscribed.sh <appid> [firefox_profile_dir]
flags:
-m or --missing: only fetch the mods that aren't in the .acf file of the game
-c or --copy: copy mods link to clipboard instead of creating a file 

<appid> is required. [firefox_profile_dir] is optional — omit it and the
script auto-detects your Firefox profile; provide it only if auto-detection
fails.

Disclaimer: this tool was developed using AI
```
